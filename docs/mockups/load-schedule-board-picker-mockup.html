What changes

  1. One row on every tab. The panel buttons stay while they all fit on the row beside the tabs (MDB, SMDB, MCC today), with no filters. The switch is by window width, not a fixed number.
  2. When they do not fit, a Filter button appears on the row. Its menu has Floor (from Building information), Fed from (the source panel) and Status (Not filled, Fails a check, Done), plus Building and New / existing when the project has more than one. Each choice shows how many panels it has and how many are not filled. Chosen filters show as tags on the row (× removes one).
  3. Opening a panel sets Floor to its floor, so the row shows that floor's panels (DB-72 … DB-83 for DB-83). You can choose All floors or another floor.
  4. If the filtered panels still do not fit, the row ends with + n more. It opens the full list with a search box (number, name or room), grouped by floor, with the row's filters applied.
  5. Number order: DB-1, DB-2 … DB-83, instead of the supply order (DB-GF1, DB-41 … DB-83, DB-1 … DB-40 in your picture). The ribbon's previous / next follow it.
  6. Filters are kept per tab while the project is open.
  7. Space: with 84 DBs, the tabs and panels take .

Decisions for you

  • A. Filters: Floor, Fed from, Status, and Building and New / existing when they apply, in one Filter menu (recommended). Any to add or drop?
  • B. Opening a panel sets Floor to its floor (recommended), or Floor stays as you left it?
  • C. When to show filters: when the buttons no longer fit on the row (recommended), or above a fixed count (say 12)?
  • D. Order: number order for the buttons, the list and the ribbon's previous / next (recommended), or keep the supply order?
  • E. The select at the top right (every panel of the project): keep it (recommended), or remove it because "+ n more" can find any panel?
