Design CAD — selection, grips and opened drawings

Proposal mockup, 2026-11-15. Today and proposed. Graphite dark; one light-theme check at the end.

An opened drawing: today and proposed

Today

  1. Picked column: only thicker, in nearly the same green: easy to miss.
  2. Picked text: not marked at all (only line pieces are redrawn).
  3. No grips on objects of an opened drawing. A drawn object gets grips only when it is the only one picked.
  4. Right-click: Erase, Deselect all, Properties (a block also gets Count instances, Explode into drawn objects, Copy as a block, Crop).
  5. A window over the drawing picks nothing from it: SEL Nothing in the window.

Proposed

  1. Dashed in its own colour with a blue halo: reads on any layer colour.
  2. A picked text gets a box.
  3. Grips by object: corners and side middles; a circle's centre and quadrants.
  4. The same menu as objects drawn in the app.
  5. Window and crossing pick drawing objects too.
  6. Hover stays amber; picked is blue and dashed, never the same look.

Grips by object (the same for drawn objects and objects of an opened drawing)

Square. A point: drag to move that point. The centre of a circle, arc or ellipse, a line's middle and a block's base point move the whole object.
Bar. A side's middle (polylines, rectangles, hatch outlines): drag to move that side, kept parallel.
Diamond. A size: drag to change a radius, an axis or a note's width; the centre stays.

Several objects picked

Grips on every picked object, up to 100 (a Drafting settings value); above that, the picked look only, so large selections stay fast.

Today: no grips once two or more objects are picked.

Editing takes the object over as a drawn object in its own layer, colour and linetype. The drawing file on disk is not changed until Save DXF / Save DWG, which writes the edited object as a normal entity. Undo puts the original back.

Decisions to make

  1. Objects of an opened drawing: editable like drawn objects, taken over on the first edit — or kept read-only with a clear note.
  2. Picked look: dashed in its own colour + blue halo — or thicker in the selection colour, or dashed only.
  3. Grips with several objects picked: on each, up to 100 objects — or one object only (today).
  4. Circle: centre + 4 quadrants — or centre + 1 radius grip (today). Arc: centre, 2 ends and middle — or centre only (today).
  5. Protecting an architect's plan from edits: lock its layers or attach it as a reference (both exist today) — or a new Lock drawing switch.
